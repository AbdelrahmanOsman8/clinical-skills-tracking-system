# Clinical Skills Tracking System

## Overview
This Python project manages and tracks clinical skills of healthcare professionals using an SQLite database. It simulates a simple system to record skill development and training progress.

## Objectives
- Record healthcare staff skills
- Update progress in skill training
- Delete or manage skill entries
- Provide a simple command-line interface

## Features
- Add new clinical skills
- Show all recorded skills
- Update training progress
- Delete skills

## Technologies
- Python 3
- SQLite

## Healthcare Relevance
Skill tracking is vital for healthcare professionals to ensure continuous learning and competency. This project simulates part of Clinical Workforce Management and supports digital health processes.

## Future Improvements
- Add user authentication
- Integrate with hospital EMR systems
- Implement web-based GUI for staff management
- Track skill certifications and expiry dates
